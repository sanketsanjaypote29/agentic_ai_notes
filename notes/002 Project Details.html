Project 01
Trading & Financial Agent

Build an intelligent financial assistant that acts as a personal wealth advisor. The agent accepts natural language queries or uploaded financial data, autonomously analyzes the user's situation, and delivers personalized, research-backed investment recommendations, dynamically updated as goals or market conditions change.

What the agent should do

  • Accept queries like "I have ₹50,000 to invest and want low-risk returns over 5 years" or allow users to upload bank statements / portfolio snapshots
  • Analyze the user's financial profile: income, expenses, savings rate, risk appetite, and investment goals
  • Recommend specific mutual funds, ETFs, or long-term instruments with supporting reasoning and research
  • Dynamically recalibrate recommendations if goals, income, or market conditions change
  • Optional: track portfolio performance over time and alert on rebalancing needs

Technical expectations

Multi-step agentic loop Financial API / data source Structured output Session memory Tool use

Project 02
Agent Infrastructure SaaS

Build a SaaS platform where users or enterprises describe their project requirements in plain language, and the agent designs the optimal infrastructure setup. The platform then monitors that infrastructure in real time, tracking compute resources, API token budgets, LLM Token budgets and system health, and proactively surfaces optimization recommendations.

What the agent should do

  • Accept a requirements description like "We're building a RAG pipeline for 10,000 daily users with sub-2s latency" and recommend a full infra stack with cost estimates and trade-offs
  • Deploy or simulate a monitoring dashboard tracking CPU/memory/GPU usage, API token consumption (external service calls), LLM token usage (prompt + completion tokens per request), latency, errors, and budget utilization
  • Watch both API tokens and LLM tokens independently: detect burn rate spikes, per-request cost anomalies, and projected budget overruns for each
  • Surface actionable recommendations based on observed token data (e.g., "Your prompt tokens are 3x the completion tokens; consider compressing your system prompt" or "Switch to a smaller model for classification tasks; projected savings of 40% on LLM costs")
  • Optional: auto-generate Terraform / Docker configs based on the recommended stack

Technical expectations

Agentic reasoning loop Monitoring dashboard UI API token tracking LLM token tracking Optimization recommendations Infra cost analysis Tool use

Submission Criteria

What You Must Submit

Every submission (solo or group) must include all five of the following. Incomplete submissions without a working demo will not be evaluated.

💻 Working Code
The project must run end-to-end without critical errors. The core agentic loop must be functional and demonstrable. Broken or purely scaffolded code will not be accepted.
🐙 GitHub Repository
Public repo with clean, readable code. Must include a README.md covering: setup instructions, architecture overview, tools & APIs used, and how to run the project locally.
🎬 Demo Video
5–10 minute screen recording showing the agent in action with real inputs and real outputs. Upload to YouTube (unlisted) or google drive. No slideshows; we need to see it working live.
🗺️ Architecture Diagram
A diagram (hand-drawn or digital) showing how components connect: the agent loop, tools, data sources, external APIs, and the flow of information. Include this in your README or as a separate file.
📝 Reflection Note
A short written section (in the README or as a separate doc) covering: what worked, what didn't, key design decisions you made, and what you'd improve with more time.
Additional Notes
  • Solo submissions are held to the same standard as group submissions; scope your project accordingly
  • You may use any LLM API (OpenAI, Anthropic, Gemini, etc.) and any framework (LangChain, LlamaIndex, custom, etc.)
  • Open-source tools and free-tier APIs are strongly encouraged to keep costs manageable
  • Partial implementations are acceptable only if the core agentic loop is working and clearly demonstrated in the demo video
